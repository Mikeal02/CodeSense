## 🚀 Project Overview

**CodeSense** is an AI-powered web application that helps developers **understand, navigate, and analyze complex codebases** with ease. Whether you’re exploring a new project, preparing for technical interviews, or generating project-specific insights, CodeSense provides a powerful, interactive environment to make coding exploration intuitive and efficient.

## ✨ Key Features

- **AI-Powered Code Analysis** – Deep insights into project structure, logic, and functionality.
- **Instant Project Overview** – High-level summary of repositories, tech stack, and core responsibilities.
- **Interactive Project Map** – Visualize folder structure, dependencies, and critical files.
- **Execution Flow Tracing** – Understand step-by-step logic for features or user interactions.
- **Teach-Me Mode** – Learn codebases interactively with interview-ready explanations.
- **Ask Anything** – Natural language queries directly grounded in your code.
- **Interview Preparation** – Generate questions, identify complex areas, and review answers.
- **Complexity Detection** – Detect tightly coupled or high-risk code sections for refactoring.
- **Change Impact Analysis** – Predict potential breakages from code modifications.
- **Resume Summary Generation** – Auto-generate resume bullets and tech stack summaries.
- **Code Search** – Powerful search with regex, case-sensitive, or whole-word matching.
- **Bookmarks** – Save important files or lines for quick reference.
- **Exportable Reports** – Export Markdown, JSON, or text summaries of your analysis.
- **Split View Mode** – View multiple files and interact with AI simultaneously.
- **Intuitive UI/UX** – Built with Tailwind CSS and shadcn/ui for modern, responsive interfaces.
- **Private & Secure** – Code is processed locally or via secure proxy; never stored externally.

## ⚙️ Getting Started

### Prerequisites
- Node.js & npm (`nvm` recommended)  
- GitHub or local codebase to analyze

### Installation

1. Clone the repository:

```bash
git clone <YOUR_GIT_URL>
```
2. Navigate to the project directory**:
```sh
    cd <YOUR_PROJECT_NAME>
```
3. Install NPM packages**:
```sh
    npm i
```
4. Start the development server**:
```sh
    npm run dev
```
---
### Building for Production

To create an optimized production build:

```sh
npm run build
```

## 🏗️ Core Functionality

- Header – Navigation, theme toggling, rate-limit display.
- Hero Section – Landing page for GitHub repo connection or local folder upload.
- Modes Section – Select AI analysis modes (Project Overview, Project Map, Interview Prep).
- Chat Interface – Ask questions and get AI-powered explanations.
- Command Palette – Quick navigation and actions (Ctrl+K).
- Notifications – Non-intrusive user alerts via Sonner.
- File Tree View – Browse directories, select files, and preview content.
- Code Search – Advanced search with regex, case-sensitivity, and whole-word support.
- Bookmarks & Export – Save important lines/files and export reports.
- Split View Mode – Simultaneous code viewing and AI interaction.
- Theming & Shortcuts – Light/dark mode toggle and keyboard shortcuts.
